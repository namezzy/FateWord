天机测字 — 设计规格总览

请确认以下所有设计决定，然后我们进入实现阶段

🏗️ 架构

客户端为主 + API 代理 — 梅花易数算法浏览器端运行，DeepSeek API 通过 Next.js API Route 代理

🎨 视觉风格

水墨淡雅 — 宣纸色背景（#F5F0EB），淡墨色文字（#2C2C2C），古铜色点缀（#8B7355），朱砂红强调（#C93756）

📐 页面布局

卷轴式单页 — 纵向滚动，输入框顶部居中，结果依次向下展开

🔧 技术决定

  • 框架：Next.js 14 (App Router) + React + TypeScript
  • 样式：Tailwind CSS + Framer Motion
  • 汉字库：cnchar（笔画数、拼音）
  • LLM：DeepSeek（通过 API Route 代理）
  • 单字拆分：简化方案（总笔画前半/后半）
  • 数据持久化：localStorage 保存历史
  • 适配：移动端优先响应式
  • 字体：Noto Serif SC（衬线体）

📦 核心模块

bagua.ts 八卦数据（名称、符号、五行、先天数）
hexagrams.ts 六十四卦查找表（名称、卦辞、Unicode 符号）
meihua.ts 梅花易数核心算法（起卦、动爻、互卦、变卦）
wuxing.ts 五行生克关系 + 运势权重计算
ganzhi.ts 天干地支（当前日期的干支计算）
character.ts cnchar 封装（笔画、拼音、五行映射）
fortune.ts 运势文本生成 + DeepSeek API 调用

🖼️ UI 组件

InputPanel 输入框 + 测算按钮（带起卦动画）
CharacterInfo 字解展示（拼音、笔画、五行）
HexagramDisplay 卦象展示（本卦、互卦、变卦 + 八卦符号）
FortuneCard 四柱运势卡片（事业/财运/感情/健康 + 梅花评分）
ResultPanel 结果容器（组合以上组件 + 卷轴展开动画）
