天机测字 — 架构方案

选择最适合项目的技术架构

A

客户端为主 + API 代理（推荐）

梅花易数算法、五行逻辑、卦象计算全部在浏览器端运行，保证即时响应和流畅体验。仅 DeepSeek API 调用通过 Next.js API Route 代理（保护 API Key）。

优势

  • 起卦计算即时完成，零延迟
  • 离线也能完成基础测算
  • API Key 安全（服务端代理）
  • 部署简单（Vercel 一键部署）

不足

  • AI 解卦仍需网络
B

全服务端渲染（SSR）

所有逻辑（算法 + LLM 调用）都在 Next.js Server Components / API Routes 中执行，客户端只负责展示。

优势

  • SEO 友好
  • 客户端代码极轻

不足

  • 每次测算都需要网络请求
  • 用户体验有延迟感
  • 架构更复杂
C

纯静态 + 内置解卦

完全不依赖 LLM，使用预写好的六十四卦解析文本。整个应用可导出为静态站点。

优势

  • 零运行成本
  • 完全离线可用
  • 部署最简单

不足

  • 解卦文本固定，缺乏个性化
  • 需要预写大量卦辞
